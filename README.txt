BETTY'S BITES — WEBSITE FILES

Open index.html in a browser to preview the website. The site works locally and does not need a server or account to preview.

CONTENTS
- index.html: the website page and its text
- styles/style.css: layout, colours and styling
- scripts/recipes.js: all 26 recipes, ingredients, methods and notes
- scripts/site.js: search, category filters, mobile menu and recipe pop-ups
- fonts/: the two supplied font files (Angeline Vintage and Dusty Erasers)

EDITING RECIPES
Open scripts/recipes.js in a plain-text editor. Each recipe has a title, category, description, ingredients list, method list, symbol and optional note. Keep category names as Nibbles, Fishy Fings, Nosh, Pudding or Stuff. Save the file and refresh the browser.

IMPORTANT SOURCE NOTE
The recipe collection is based on the supplied Betty's Bites cookbook/index. Some recipes in the book do not specify exact quantities or detailed steps; these are flagged where known. Please review cooking details before publishing. No original recipe photographs were available in the starter files, so cards use decorative symbols rather than invented food photography.

PUBLISHING
This folder is a static website and can be uploaded to a static hosting service. For a public web address, publish the folder contents using your chosen host.

TEMPORARY RECIPE IMAGES
Each recipe currently uses a labelled SVG placeholder in images/recipe-placeholders/. Replace each SVG with a food photo saved as a JPG or PNG, then update that recipe's "image" path in scripts/recipes.js. For easiest replacement, keep the current SVG files until you have your photos ready. The placeholder art intentionally says REPLACE WITH YOUR PHOTO.


ADDING YOUR OWN FOOD PHOTOS (NO CODE EDITING NEEDED)
---------------------------------------------------
1. Open the images folder in this website folder.
2. Copy your JPG photos directly into images (not into recipe-placeholders).
3. Name each photo using the recipe filename list below. Use lowercase letters and hyphens.
4. Refresh index.html in your browser. If a photo is missing, the illustrated placeholder will show instead.
